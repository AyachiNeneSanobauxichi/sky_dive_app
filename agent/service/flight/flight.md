# flight

## v1

- 航线（load）= 排班的最小单位：**某个跳伞地点 · 某个起飞时刻 · 某架飞机**的一次爬升，上面挂顾客与摄影师的名额和名单。
- 航线 tab（`/flights`）就是**航线列表**：
  - 每条卡片自上而下给：起飞时刻（最大，时刻表靠它扫）· 日期（今天 / 明天 / 具体日期）· 航线代号 · 状态角标（满员 / 已起飞）· 跳伞地点（名称 · 都道府県）· 机型与出舱高度 · 顾客与摄影师**两条名额占用条**（`3/6` + 进度 + 还剩几位）。
  - 已起飞的航线整块压暗并标「已起飞」，**不隐藏**（当天要回看飞了哪几班）。
  - 点卡片 → 航线详情弹层（名单）。
- **搜索**：顶部搜索框，按「代号 / 跳伞地点 / 机型」即时本地过滤（空格分词，全部命中才留下）；有内容时出清除按钮；搜索时在筛选栏下方显示结果条数。
- **排序**：两个 chip 切换「最早优先 / 最晚优先」，只按起飞时刻排（默认最早优先）。搜索词与排序方式在 tab 之间切换时不丢。
- **管理员**（视角开关见下）额外可以：
  - **新建航线**：筛选栏右侧「添加航线」按钮 → 表单弹层。
  - **编辑航线**：卡片右下角铅笔按钮 / 详情弹层右上角铅笔按钮 → 同一张表单（预填）。
  - **删除航线**：卡片右下角**垃圾桶**按钮 → 二次确认弹窗（写清有几个人会失去名额）→ 成功 toast；删除在途时该按钮禁用防连点。
- **航线表单**（新建 / 编辑同一张）：
  - 字段：航线代号（必填，≤12 字符）· **跳伞地点**（单选药丸，必填）· 起飞日期 + 时刻（系统选择器，不允许排到过去）· 机型（必填，≤32 字符）· 出舱高度（固定档位 4000/8000/10000/12000/14000 ft 单选）。
  - **名额上限可设置**：顾客与摄影师各一个 +/- 步进器（顾客 1–24、摄影师 0–6）；编辑时**下界不得低于已分配人数**，到界时在下方说明「已经排了 N 人」。
  - 校验错误就地显示在字段下方（不用 toast）；提交按钮带忙碌态防重复提交；失败保留已填内容。
- **航线详情弹层**：航班信息 + 两条名额占用条 + **名单**（顾客 / 摄影师分组）。
  - 管理员每组有「添加顾客 / 添加摄影师」按钮 → 选人弹层（候选池，可按姓名搜索，**已在本航线上的人不出现**）；该角色满员时按钮禁用。
  - 名单每行可「移出本航线」（二次确认 → 成功 toast），移人期间该行换成内联转圈。
  - 客人视角看到同一张详情，只是没有增删入口。
- **管理员视角开关**：页头右上角盾牌图标切换「管理模式 / 客人视角」。⚠️ 临时方案——真实角色应由后端在登录响应里下发，届时去掉开关。
- 异步四态齐全：加载 = 用真实卡片喂占位数据的骨架屏；空 = 分「搜不到（引导清除搜索）」与「一条都没有（管理员引导新建 / 客人引导等通知）」；错误 = 首屏失败给内联重试卡，**刷新失败只弹 toast、不清列表**；有数据 = 首屏逐项入场（只给前 6 条）。

## v2

- **管理员身份改为后端下发**：不再有页头的「管理模式」切换开关。是否显示排班入口，取决于登录用户的角色（`userInfo.role == "staff"`，见 `agent/service/auth/auth.api.md` v2）。客户端只做入口显隐，权限边界由服务端把。
- **详情 / 新建 / 编辑从底部弹层改为真实页面**（挂在 flights 分支下，底部 tab 保持可见、返回栈跟着该 tab）：
  - `/flights/:loadId` 航线详情（名单）
  - `/flights/new` 新建航线
  - `/flights/:loadId/edit` 编辑航线
  - 好处：可深链接（推送直达某条航线 / 分享给同事）、切 tab 回来还停在原页。
  - 深链接直达时列表可能还没到：详情页与编辑页先画骨架；那条航线已被删除时给「这条航线已经不在了」+ 返回列表。
  - 表单页填了一半返回会**先问一句**（`PopScope`），确认后才丢弃。
  - 选人（候选池）仍然是底部弹层——它是一次性的选择动作，不值得占一层路由。
- **列表按天分段，段头吸顶**：段头给「今天 / 明天 / 具体日期 + 该天几班」，材质与底部导航条同一套毛玻璃。卡片不再各自重复日期。
- **移出名单改成「先做 + 可撤销」**：不再弹二次确认，直接移出并给一条带「撤销」的 toast（停留 6 秒）。撤销即把人原样排回；这几秒里位置被别人占走时照实报「已满」，不假装成功。删除航线仍然保留二次确认——那个不可逆。
- **名额展示从进度条改为座位点阵**：已占实心、空位描边，一眼能数出还剩几个（名额是可数的座位，不是百分比）。座位超过 12 个才退回进度条；某角色名额为 0 时显示「不设名额」，不显示「满员」。

## v3

- **搜索 + 排序工具条吸顶**：标题随内容滚走，工具条钉在顶部；往下滚时排序行淡出并收起，只留搜索框（排班时"边滚边改搜索词"是高频动作，工具条滚走等于每次筛选都要来回一趟）。材质与日期段头、底部导航条同一套毛玻璃。
- **名单可拖拽排序**：名单顺序 = 登机 / 出舱顺序，运营在舱门口照着它叫人。每行右侧给拖拽把手（只有运营看得到），松手立刻发请求、不等回包再动 UI；失败时用服务端的真实顺序覆盖回来并提示——顺序这种"看起来已经成了"的操作，失败必须有声音。
- **名单支持左滑移出**：与移出按钮走同一条「先做 + 可撤销」流程。左滑是快捷方式，**每行的移出按钮始终保留**（隐藏手势不能是唯一入口）。
- **客人视角出现预约入口**（详见 `agent/service/booking/booking.md`）：
  - 列表卡片：未起飞、没满、没约过时给「预约」（secondary，一屏最多一个 primary 的额度留给详情页）；已约过改显示「已预约」角标。
  - 详情页底部：「预约这一班」/「取消预约」主行动；取消是二次确认。
  - 满员 / 已起飞一律**禁用**而不是点了报错。
