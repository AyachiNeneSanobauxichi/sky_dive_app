# booking

## v1

- 预约 = **客人在某条航线上占一个顾客位**。因此「我的预约」和「航线名单」是同一份数据的两个视角：客人预约成功的那一刻，该航线的顾客名额立刻少一个，运营在名单上也马上看得见他。
- **航线列表（flight tab）里的客人视角**：
  - 每张卡片在未起飞且顾客位未满时，右下角给一个「预约」主行动（一屏最多一个 primary 的规则由卡片自身尺寸消化：按钮是 small）。
  - 已经预约过的航线，卡片改为显示「已预约」角标，不再给按钮（管理入口在详情页）。
  - 已起飞 / 已满的航线不给按钮（禁用而不是点了报错）。
- **航线详情页的客人视角**：底部给「预约」/「取消预约」主行动；取消是**二次确认**（客人取消行程有后果，且位置可能立刻被别人占走，撤销未必还原得回来）。
- **预约 tab（booking）**：
  - 列出「我的预约」= 我在名单上的航线，按起飞时刻由早到晚。
  - 每条给：起飞时刻 + 日期 · 航线代号 · 跳伞地点 · 机型与高度 · 状态（即将起飞 / 已起飞）· 取消入口。
  - 已起飞的行程压暗并标「已起飞」，保留在列表里（客人要回看自己跳过哪几班），且不再给取消。
  - 点条目进对应的航线详情页。
  - 四态齐全：加载=骨架、空=「还没有预约」+ 一步跳到航线列表、错误=内联重试、有数据=逐项入场。
- 预约与取消都要有明确的成功提示；失败按业务码给人话（满员时告诉他"这班刚满了，换一班"，而不是"操作失败"）。
