# user

## v1

- 模块职责：**用户设定**。账号信息与生成偏好（昵称 / 头像 / 故事风格 / 语气强度 / 敏感内容边界等），相当于 story 生成时的"作者设定"。
- 关系：user 提供风格设定 → story 生成时使用；轨迹素材来自 track。
- 位置：首页底部导航**第 3 个 tab**。
- 退出登录入口归本模块（v1 之前挂在首页 AppBar 上，现移入）。
- 本期只做**占位页**：空态（品牌图标 + 一句说明 + 引导按钮）+ 退出登录；按钮点击给"即将上线"轻提示，不接接口、不做真实设置项。

## v4

- 添加语言与黑白主题两个设置
- 语言跟随手机系统 黑白主题默认黑色
- 并根据 mini-program 中的 api-doc 调通编辑 user 信息的接口
- 编辑 user 的 ui 请自行设计
  -- 两个设置放在「偏好」区，和「功能」区分开：偏好是"设成什么就一直是什么"，功能是"点一下做一件事"，混在一起会让退出登录挨着语言设置。设置项右侧直接显示当前取值，点开是底部单选面板，选完即生效、不需要确定按钮。
  -- 语言三档：跟随系统（默认）/ 简体中文 / English。**"跟随系统"必须是独立一档**，不能拿 `zh` 当默认——否则用户换了手机系统语言 app 不跟着变，会被当成 bug。
  -- 主题两档：深色（默认）/ 浅色，不提供"跟随系统"（本产品视觉基底是星空夜幕）。
  -- 偏好在**首帧之前**读出来（`main()` 里预读后注入），否则会看见深色闪一下再变浅色；登出**不清除**偏好（`SecureStorage.clear()` 改为逐项删）。
  -- 编辑表单字段：昵称、性别、生日、城市、职业、行业、公司、爱好、MBTI、个性标签、理想生活。**年龄与星座不给输入框**，由生日推导并就地显示，让用户确认推导对不对；各填一遍只会制造自相矛盾的素材。
  -- 表单编辑的是**工作副本**，不落盘不污染全局状态；保存失败不清空、不回滚，用户填的内容原样留着。
  -- 契约里的童年/高光/低谷/未来愿景属 track 的地盘，不在本表单范围内，保存时也不回传（发 null 等于把别处填的清空）。
  -- 完成度（星厉契合度）改为统计 10 项可填字段，年龄/星座不计入（避免生日一项顶三项）。
