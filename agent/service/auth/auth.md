# auth

## v1

- 首先删除现在寄存的所有业务页面和功能
- 首页先用占位页面替代
- 先来做登录页面
- 需要输入手机号 验证码 还有发送验证码的按钮
- 有登录按钮验证码
- 需要有标题和勾选用户协议等标准的登录页面内容
- 其余 ui 自行设计

## v2

- 登录页面的 2fa code 不要在输入时校验 输入时有红框不好看优化一下

## v3

- 手机号同样**不在输入时校验**（此前敲到第 5 位就红着「手机号格式不正确」）。校验只发生在两个时刻：① **离开输入框**且已经输过内容——人已经填完走人了，这时的半截号码才是真错；② 点了**获取验证码**。
- 空着离开输入框不算错：没填就走开多半只是想先看看下面写了什么，冲他喊「请输入手机号」是无中生有；等他去点获取验证码或登录时再拦。
- 报过一次错之后转为实时校验，用户改对的那一刻红字自己消失；而**重新聚焦回输入框就复位**，回到「输入时不判」。
- 登录按钮本就要求号码合法才可点，所以提交那一刻不会再冒出手机号的错误。
