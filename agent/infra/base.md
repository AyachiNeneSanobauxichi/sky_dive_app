# base

## v1

- 本项目是**日本跳伞运营商的 C 端 app**（工作名 SkyDive）：客人在这里挑航线（drop zone / 机型 / 高度）、看天气窗口、下预约、管理自己的跳伞记录。
- 目标用户是普通消费者，且**同时包含本地客人与外国游客**：界面语言支持日语 / 英语 / 中文，默认跟随手机系统。
- 本项目是面向 C 端项目，所以 **UI 是重中之重**：要现代、要贴合本主题（高空 · 云 · 深浅双主场），有更好的 UI 方案一定提醒我。
- **深浅两套主题都是一等设计目标**——浅色是白昼晴空（白天挑航线的主场景），深色是暮色高空（黄昏跳与夜里查行程）。不允许只做好一套。
- 暂时没有后端接口，用 mock 把**完整交互链路**（含加载 / 空 / 错误态）跑通；接真接口后立即删除 `data/mock/`。

## v2

- 首页底部做一个 bottom tab，承载三个模块：**flight（航线）· booking（预约）· account（账号）**。
  - 顺序即动线：先看有什么可跳 → 再看自己约了什么 → 最后才是账号设置。
  - 落地页是 flight。
- 认证支持两条路并存，指向同一个账号体系：
  - **邮箱 + 密码**：主路径，也是唯一能"注册"的入口（要留下能收行程确认与保险单的邮箱）。
  - **手机号 + 短信验证码**：给现场临时下单的客人，未注册号码由后端直接建号，没有独立注册页。
- 账号页要能切**外观**（跟随系统 / 白昼 / 暮色）与**语言**（跟随系统 / 日本語 / English / 中文）。
